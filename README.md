# 🌤️ Weather Forecast App

A modern, responsive weather application built with React that provides real-time weather data for cities worldwide. Features include debounced search, dark mode toggle, persistent recent searches, and a clean, intuitive user interface.

## ✨ Features

- 🔍 **Real-time Weather Data** – Fetches live weather from WeatherAPI.com
- ⚡ **Debounced Search** – Optimizes API calls with 500ms delay
- 🌙 **Dark/Light Theme** – Toggle between themes with persistent preference
- 📋 **Recent Searches** – Saves last 5 searches using localStorage
- 🎨 **Responsive Design** – Works perfectly on mobile, tablet, and desktop
- ⚠️ **Error Handling** – Graceful error messages and fallback mechanisms
- 📍 **City Coordinates** – Displays latitude and longitude for each city
- 💨 **Detailed Weather Info** – Temperature, feels like, humidity, wind speed, pressure, visibility, and cloud cover

## 🛠️ Tech Stack

- **Frontend:** React 18, JavaScript (ES6+)
- **Styling:** CSS3 with CSS Modules
- **API:** WeatherAPI.com REST API
- **HTTP Client:** Axios / Fetch API
- **State Management:** React Context API
- **Storage:** LocalStorage for preferences and history
